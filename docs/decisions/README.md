# 架构决策记录 (ADR)

本目录记录 AutoTrade 项目设计过程中交互达成的**关键决策**，每个文件是一个 ADR (Architecture Decision Record)。

## 用途

- **ADR 记"为什么"** —— 决策的背景、选项、理由。
- **spec 记"做什么"** —— 系统的具体设计（见 `docs/superpowers/specs/`）。
- 两者互补：未来回顾时，ADR 解释"当时为什么这么选"，spec 说明"具体怎么做"。

## 使用约定

- 编号递增、不回收。即使决策被推翻，原文件保留历史，新增文件标注"替代 xxxx"。
- 每次达成新的关键决策，追加新 ADR 并更新下方索引。
- 文件命名: `NNNN-<kebab-case-title>.md`。

## ADR 模板

```markdown
# ADR-NNNN: 标题

- 状态: 已接受 | 已推翻 | 已替代
- 日期: YYYY-MM-DD
- 决策者: 用户 + ZCode

## 背景
（为什么需要做这个决策？面临什么问题/选项？）

## 决策
（最终选了什么？）

## 理由
（为什么这么选？权衡了什么？）
```
